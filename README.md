# B1G IPTV Website

A responsive, single-page HTML website prepared for GitHub Pages.

## Files

- `index.html` — main website
- `sitemap.xml` — search-engine sitemap
- `robots.txt` — crawler instructions
- `404.html` — custom GitHub Pages error page
- `.nojekyll` — prevents GitHub Pages Jekyll processing

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.
7. If using `b1giptvuk.com`, configure the custom domain in GitHub Pages and update DNS at your domain provider.
